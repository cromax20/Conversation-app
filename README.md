# Conversation-app

**Atelier de personnages** : une page unique (`index.html`) pour pratiquer une langue en discutant avec un personnage généré au hasard.

- Décrivez une situation (ou choisissez-en une), la langue à apprendre, votre niveau (A1–C1) et votre langue.
- Un personnage (nom, âge, ville, métier, caractère) est créé et un prompt de jeu de rôle est généré.
- Publiée comme Artifact sur claude.ai, la page discute directement avec le personnage.
- Ouverte ailleurs (fichier local, GitHub Pages…), le chat n'est pas disponible : copiez le prompt affiché et collez-le dans Claude.

Pour l'essayer : ouvrez `index.html` dans un navigateur.
